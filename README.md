# 检测实验室简易排班管理系统

课程项目：**使用 AI 工具辅助完成检测实验室简易排班管理系统**

一个基于 React + Node.js 的实验室当日排班系统：录入当日样本任务量，一键生成考虑技能匹配、在岗状态、可用工时、样本优先级、人员效率与成本效益的排班计划，并提供收益分析、告警建议、图表报表。

## 功能一览

- 工作看板：当日任务量、在岗人员、完成率、利润、任务分布一目了然
- 智能排班：任务量录入 → 工作量预测 → 一键排班 → 明细/告警/建议
- 手动调整：人员离岗、技能、工时调整后一键重排
- 人员/样本配置：可视化维护参数（加分项）
- 统计报表：收益构成、人员利用率、样本完成情况、历史趋势四类图表（加分项）
- 默认数据一键恢复（加分项）

## 环境要求

- Node.js ≥ 18（开发验证环境为 v25.8.2）
- npm（国内网络建议使用镜像：`npm config set registry https://registry.npmmirror.com`）

## 快速开始

### 方式一：生产模式（推荐，一个进程跑全部）

```bash
# 1. 安装依赖（根目录 + server + client 共三个）
npm run install-all

# 2. 构建前端
npm run build

# 3. 启动（API + 前端页面，单进程）
npm start
```

浏览器访问 http://localhost:3001 即可使用。

### 方式二：开发模式（前端热更新）

```bash
npm run install-all
npm run dev
```

前端 http://localhost:5173 （自动代理 API 到 3001 端口）。

## 运行测试

```bash
npm test
```

输出三大场景（正常排班 / 调整后重排 / 人手不足）共 17 条断言的结果。
